## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies the composed front page (`entry.png`, 1024×1024) to `out/entry.png`, byte for byte, and verifies the copy. No network, no dependencies — Node standard library only.

## About the entry

Built for the [make.fun bounty "Sum up 18 November's world news in one image"](https://make.fun/bounty/news-image-20261118).
